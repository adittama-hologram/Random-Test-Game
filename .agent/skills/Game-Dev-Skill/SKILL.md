# Web Dev
This game is web based so please also follow the WebDev-Skill

# Game Description
The main concept of this game is "Pong" Game, where the player must face a CPU to compete and prevent for the ball to enter players area.

# Start of the Game
Before the game started player is instructed to input their name, this name will then recorded later for the Leaderboard. after the player enter their name they can press the "start" button to start the game

# Timer
Game time is limited to 60 second, from then the game will end. and then player and Cpu score will be shown in popup.

# End Game Popup
When the game is finished, pop up will appear. this popup show the player and Cpu score. Retry button is on the bottom of this popup for the player to play again. next to the retry button there is leaderboard button, this button will show a leaderboard popup

# Leaderboard
Leaderboard score is stored in database, this leaderboard is record the player name and player/cpu score. The Leaderboard popup will show this score for the 10 Best.

# Controll
the game contoll the player using arrow on user's keyboard, and if the player is using mobile device there will be 2 arrow button to controll player movement.

# Design
- the game design is colorfull, using purple and white as their main color.
- make the player bar to be blue, and the cpu bar is red, 
- the back ground of the game is space with blinking animation of stary space.
- everyime the ball is hit the player/cpu bar make a shaky pop animation.
- add sfx everytime the ball is collided/bounced.
- add sfx everytime ui button is clicked
- add sfx when the game is ended.
- add simple looped bgm when the game is playing
